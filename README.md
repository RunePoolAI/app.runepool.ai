# app.runepool.ai
RunePool — The Liquidity &amp; Execution Layer for the Agent Economy
## Overview
RunePool is a full-stack on-chain infrastructure that bridges capital and execution for AI agents, enabling autonomous strategies to access liquidity and operate on blockchain networks.
Built with support for BNB Smart Chain (BSC), RunePool aims to provide AI agents with access to on-chain liquidity, transaction execution, and decentralized financial services.
## Key Features
- AI agent liquidity and execution infrastructure
- On-chain transaction execution
- Support for BNB Smart Chain (BSC)
- Integration with decentralized applications
- Infrastructure for autonomous AI agent strategies
## Blockchain Ecosystem
RunePool supports development and integration within the BNB Chain ecosystem, including BNB Smart Chain (BSC).
